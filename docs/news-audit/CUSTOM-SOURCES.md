# إضافة مصادر المستخدم: الفحص ثم المعاينة والاعتماد

المسار القديم كان يحفظ kind=web دون أي جالب. المسار الجديد لا يحفظ الموقع أثناء الفحص؛ يتطلب معاينة ثم اعتمادًا صريحًا.

1. رابط HTTPS عام بلا بيانات دخول أو منفذ خاص أو عنوان IP/اسم محلي معروف. لا تُتبع تحويلات HTTP؛ يلزم الرابط النهائي المباشر. هذا ليس تحقق DNS شاملًا ولا خدمة جلب على خادم.
2. قراءة الصفحة بمهلة 12 ثانية. الويب يحترم CORS ولا يرسل credentials. حد 2MiB أثناء قراءة الويب؛ أندرويد يستخدم CapacitorHttp، ويتحقق من الحجم بعد وصول الاستجابة إلى الجسر، وليس قبل تنزيلها.
3. RSS/Atom مباشر أو اكتشاف 3 روابط تغذية معلنة كحد أقصى ضمن الناشر نفسه. بديل: قالبا HTML للبطاقات/articles. HTML يتطلب خبرين مختلفين وروابط تفاصيل ضمن الناشر؛ RSS يتطلب خبرًا صالحًا واحدًا.
4. معاينة آخر/أول عشرة عناصر مستخرجة وفق ترتيب المصدر؛ يعرض التطبيق تاريخ النشر المتاح دون اختراعه. RSS يتجاهل التاريخ غير القابل للتحليل وHTML يقبل ISO فقط، ويستبعد تاريخًا بجوار عبارة آخر أجل. لا يمكن للقوالب إثبات معنى كل تاريخ أو أن كل عنوان خبر؛ المستخدم يراجع المعاينة.
5. عندما تُقرأ الصفحة ولكن لا تنجح القوالب، يُتاح اقتراح محددات CSS من Gemini بعد موافقة واضحة على إرسال مقتطف. يستخدم مفاتيح المستخدم المتحققة وآلية الفشل البديلة الموجودة. لا تُرسل الصفحة إلى AI تلقائيًا. المقتطف يستبعد scripts/forms/inputs/navigation وعناوين URL خارج الناشر ومعاملات query، وحده 30000 حرف. لا ننفذ كودًا يولده المزود ولا نتبع روابط يقترحها.
6. يُختبر JSON المقترح على DOM الصفحة المقروءة. نقص المحددات أو فشل استخراج خبرين يرفض الإعداد. لا يُحفظ شيء إلا بالاعتماد.
7. التحديث الفعلي للمصادر المعتمدة يستخدم RSS أو محددات HTML المحفوظة. الفشل يحفظ آخر أخبار ناجحة ويعرض سببه عند اختيار المصدر. المصادر القديمة غير المفحوصة تُحفظ مع تنبيه لإعادة إضافتها.
8. الاعتماد يحفظ المصدر وأخبار المعاينة مع استعادة مفاتيح الأخبار السابقة إذا فشل جزء من الكتابة. فشل الاستعادة نفسه يُذكر بدل الادعاء بأنها نجحت. حذف مصدر خاص يزيل أخباره المخزنة أيضًا، وتُستبعد استجابة تحديث متأخرة لمصدر حُذف أثناء الجلب؛ البنوك والإحصاءات ومفاتيح AI لا تُمس.

## الحدود

المواقع التي تحتاج JavaScript أو تحويل رابط/حماية/جلسة خاصة أو التي تمنع CORS قد لا تعمل في الويب. AI لا يتجاوز قيود الوصول ولا يثبت ملاءمة موقع لم يصل محتواه. المصادر المضافة تبقى محلية لكل جهاز ولا تدخل تلقائيًا في تغذية البناء العامة. قوالب HTML تجلب العنوان والملخص والرابط وتاريخ النشر؛ لا تجلب تلقائيًا متن كل صفحة مقال. الصور ليست جزءًا من القالب العام لهذه الجولة.

## التحقق

اختبار news-source-validation.mjs يغطي RSS/Atom واكتشاف التغذية، استبعاد الروابط غير الآمنة والقوائم، HTML، رفض الإعدادات الوهمية، موافقة AI، المعاينة قبل الاعتماد، تحديث مصدر خاص، التكرار، الحذف، استعادة التخزين بعد فشل متأخر وطلب HTTP الأصلي في Android عبر mock. لا يعني الاختبار اتصالًا حقيقيًا بـGemini أو تجربة هاتف فعلي. يسجّل CI بناء APK واختبارات المتصفح؛ تظل تجربة الهاتف الحقيقية منفصلة.
