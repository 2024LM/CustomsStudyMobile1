# Raje3

**Raje3** تطبيق عربي للمراجعة الذكية وإدارة بنوك الأسئلة والمراجع، مصمم للطلبة والمترشحين للمباريات والاختبارات. يعمل كتطبيق Android وكتطبيق ويب، مع واجهة RTL وتجربة متوافقة مع الهاتف والكمبيوتر.

## ما الذي يقدمه Raje3؟

### الأسئلة والجلسات
- تصفح الأسئلة والبحث فيها حسب البنك والمحور.
- جلسات مراجعة واختبارات تفاعلية.
- دعم أسئلة **QCM** و**صح/خطأ**.
- تصحيح فوري مع الشرح.
- مراجعة الأخطاء والمفضلة.
- جلسات ذكية تعتمد على الأخطاء والأسئلة المستحقة والجديدة.

### بنوك الأسئلة
- دعم عدة بنوك أسئلة في نفس التطبيق.
- استيراد بنوك من ملفات **XLSX** بعد فحصها والتحقق منها.
- تنزيل بنوك منشورة للتطبيق.
- مشاركة البنوك.
- إنشاء بنوك من أسئلة مولدة بواسطة الذكاء الاصطناعي.
- تنظيم البنوك حسب مجالات الدراسة.

### المراجع
- مكتبة مراجع قابلة للتوسع.
- دعم Markdown وWord وPDF.
- قارئ PDF بتمرير عمودي مستمر.
- تنزيل المراجع للاستخدام المحلي.
- قراءة صوتية للنصوص.
- أدوات Gemini لتلخيص المرجع وإنشاء أسئلة وFlashcards منه.
- حفظ الأسئلة المولدة من المرجع كبنك أسئلة مستقل.

### الذكاء الاصطناعي
- مساعد Gemini داخل التطبيق.
- دعم عدة مفاتيح API مع اختبارها والتبديل التلقائي عند فشل أحدها.
- محادثات محفوظة.
- دعم الصور والملفات والروابط كمصادر.
- اقتراح مصادر وروابط وفيديوهات YouTube.
- إنشاء بنوك وملخصات وأسئلة من المحتوى.
- سجل للطلبات والاستجابات لتسهيل التشخيص.

### خطة المراجعة والتنبيهات
- تحديد تاريخ الامتحان.
- حساب هدف مراجعة يومي تلقائيًا.
- تنبيه يومي ديناميكي حسب التقدم.
- إرسال سؤال مراجعة دوري في وقت وفاصل يحدده المستخدم.
- دعم أصوات الهاتف أو ملف صوتي مخصص للتنبيه.

### القراءة الصوتية
- اختيار صوت من الأصوات المتاحة في الهاتف.
- دعم القراءة العربية للمراجع والأسئلة.
- إعدادات خاصة بتحسين النطق العربي.
- استمرار القراءة في الخلفية على Android.
- إشعار دائم أثناء القراءة مع زر لإيقاف الصوت.

### مركز الدراسة
- Flashcards.
- قاموس وملاحظات.
- Pomodoro.
- مراجعة ذكية.
- تحليل الأداء.
- سجل الجلسات.
- أدوات البحث وإدارة المحتوى.

### الإحصائيات
- نسبة النجاح وعدد الإجابات.
- الصحيح والخطأ.
- النشاط اليومي والأسبوعي والشهري.
- مقارنة الأداء الأسبوعي.
- أضعف وأقوى المحاور.
- أكثر الأسئلة خطأ.
- إحصائيات حسب بنك محدد أو جميع بنوك المجال.

### المظهر وتجربة الاستخدام
- العربية وRTL.
- وضع نهاري.
- وضع ليلي.
- وضع **حسب الهاتف** وهو الإعداد الافتراضي.
- Onboarding لأول تشغيل.
- جولات إرشادية داخل الشاشات الرئيسية.
- واجهة متجاوبة للهاتف والويب.

### التحكم عن بُعد
يستخدم Raje3 إعدادات خارجية من GitHub للتحكم في بعض الوظائف دون الحاجة إلى إصدار APK جديد، ومنها:
- معلومات آخر إصدار والحد الأدنى المدعوم.
- إشعارات وإعلانات داخل التطبيق.
- نافذة تقييم التطبيق.
- روابط التواصل الاجتماعي.

## التقنية

المشروع مبني باستخدام:
- React
- TypeScript
- Vite
- Tailwind CSS
- Capacitor
- SQLite محلي
- Android Native Java لبعض الوظائف مثل الإشعارات والتنبيهات والقراءة الصوتية

## تشغيل المشروع محليًا

```bash
npm install
npm run dev
```

## بناء نسخة الويب

```bash
npm run build
```

## بناء Android

يتم إنشاء مشروع Android وبناء APK من خلال GitHub Actions. ملف البناء الناتج يُرفع باسم:

`Raje3`

## ملاحظات البيانات

- قاعدة البيانات الحية للتطبيق داخلية ومحلية.
- ملفات Excel هي مصادر استيراد فقط وليست قاعدة البيانات نفسها.
- لا يتم تنفيذ SQL أو Macros أو صيغ Excel القادمة من الملفات المستوردة.
- بيانات المستخدم مثل الإحصائيات والأخطاء والمفضلة تبقى منفصلة عن ملفات البنوك.

## الإعلانات والأداء

- الذكاء الاصطناعي يستخدم Gemini API عبر الإنترنت؛ أزيل دعم Nano المحلي.
- لكل موضع إعلان ثابت عرض Android مستقل، مع تحديث الموقع أثناء التمرير، وإعادة المحاولة عند عودة الاتصال، وإخفائه أثناء عرض النوافذ المنبثقة أو انتقال التطبيق للخلفية.
- يستخدم التطبيق البانر 320×50 افتراضيًا. يُطلب حجم 300×250 فقط عند ضبط موضع مستقل يدعمه؛ عند فشله أو انتهاء مهلة تحميله، يعود إلى موضع البانر العادي.
- لا تُحجز مساحة للإعلان أثناء التحميل أو عند عدم توفر إعلان، ولا تترك المواضع المخفية صفوفًا أو فجوات إضافية.
- يمكن ضبط معرّفات Unity أثناء البناء بواسطة `VITE_UNITY_BANNER_PLACEMENT` و`VITE_UNITY_RECTANGLE_PLACEMENT`. في GitHub Actions، استخدم Repository Variables باسم `UNITY_BANNER_PLACEMENT` و`UNITY_RECTANGLE_PLACEMENT`. القيمة الافتراضية للبانر هي `BP_Banner_Android`؛ اترك إعداد المربع فارغًا ما لم يتوفر موضع مستقل يدعم حجمه. ظهور إعلان فعلي يعتمد على دعم الحجم وتوفر إعلان من Unity.
- يحفظ تحديث الإعدادات دفعة واحدة، ويحدّث SQLite السجلات المتغيرة داخل معاملة واحدة مع الاحتفاظ بنسخة الاستعادة.
- يحتفظ قارئ PDF بصور ست صفحات قريبة كحد أقصى ويعرض الصفحات الأخرى عند الرجوع إليها.

التحقق: `npm run build` و`node tests/resource-regressions.mjs` و`node tests/banner-layout.mjs` (يتطلب Playwright وChromium)، ثم اختبارات SQLite وبناء APK عبر GitHub Actions. تحقق على هاتف من الانتقال دون إنترنت ثم عودته، والإعلانات أثناء التمرير والنوافذ المنبثقة، ومن PDF طويل مع التكبير والتنقل.

## الأخبار واللغة

- يجرب جامع الأخبار المسارات العربية المعروفة وروابط العربية التي يعلنها المصدر نفسه. يحتفظ بالأخبار الأخرى إذا لم يجد نسخة عربية للخبر، ويختار العربية عند تطابق رابط التفاصيل أو معرّف الخبر.
- زر «ترجمة للعربية» يترجم العنوان والملخص المعروضين داخل بطاقة الخبر عند الطلب فقط، مع «عرض الأصل». لا يغير الرابط أو تاريخ الخبر، وتُحفظ آخر 100 ترجمة حسب النص الأصلي.
- Android يستخدم ML Kit محليًا دون مفتاح API. أول استخدام قد ينزّل حزم اللغة عبر الإنترنت، ثم تعمل الترجمة بعد تنزيلها دون اتصال. لا تُرسل نصوص الأخبار لخادم ترجمة من التطبيق على Android.
- نسخة الويب تستخدم Gemini المفعّل لدى المستخدم. إذا لم يوجد مفتاح مفعّل، تظهر رسالة داخل البطاقة ويبقى النص الأصلي.
- يجمع GitHub Actions الأخبار عند بناء الويب وAPK، ويستمر تحديث RSS داخل التطبيق. هذا التعديل لا يضيف تحديثًا دوريًا للمواقع التي لا توفر API.

- يعرض قسم الرئيسية معاينات متساوية الارتفاع، مع صور جانبية مجهزة وألوان وأيقونات مميزة للمصادر. أزيل مصدر البيانات المفتوحة ومسار CKAN، وتُستبعد أخباره القديمة من الذاكرة المحلية.
