# Raje3

**Raje3** تطبيق عربي للمراجعة الذكية وإدارة بنوك الأسئلة والمراجع، مصمم للطلبة والمترشحين للمباريات والاختبارات. يعمل كتطبيق Android وكتطبيق ويب، مع واجهة RTL وتجربة متوافقة مع الهاتف والكمبيوتر.

## ما الذي يقدمه Raje3؟

### الأسئلة والجلسات
- تصفح الأسئلة والبحث فيها حسب البنك والمحور.
- جلسات مراجعة واختبارات تفاعلية.
- دعم أسئلة **QCM** و**صح/خطأ**.
- تصحيح فوري مع الشرح.
- مراجعة الأخطاء والمفضلة.
- جلسات ذكية تعتمد على الأخطاء والأسئلة المستحقة والجديدة.

### بنوك الأسئلة
- دعم عدة بنوك أسئلة في نفس التطبيق.
- استيراد بنوك من ملفات **XLSX** بعد فحصها والتحقق منها.
- تنزيل بنوك منشورة للتطبيق.
- مشاركة البنوك.
- إنشاء بنوك من أسئلة مولدة بواسطة الذكاء الاصطناعي.
- تنظيم البنوك حسب مجالات الدراسة.

### المراجع
- مكتبة مراجع قابلة للتوسع.
- دعم Markdown وWord وPDF.
- قارئ PDF بتمرير عمودي مستمر.
- تنزيل المراجع للاستخدام المحلي.
- قراءة صوتية للنصوص.
- أدوات Gemini لتلخيص المرجع وإنشاء أسئلة وFlashcards منه.
- حفظ الأسئلة المولدة من المرجع كبنك أسئلة مستقل.

### الذكاء الاصطناعي
- مساعد Gemini داخل التطبيق.
- دعم عدة مفاتيح API مع اختبارها والتبديل التلقائي عند فشل أحدها.
- محادثات محفوظة.
- دعم الصور والملفات والروابط كمصادر.
- اقتراح مصادر وروابط وفيديوهات YouTube.
- إنشاء بنوك وملخصات وأسئلة من المحتوى.
- سجل للطلبات والاستجابات لتسهيل التشخيص.

### خطة المراجعة والتنبيهات
- تحديد تاريخ الامتحان.
- حساب هدف مراجعة يومي تلقائيًا.
- تنبيه يومي ديناميكي حسب التقدم.
- إرسال سؤال مراجعة دوري في وقت وفاصل يحدده المستخدم.
- دعم أصوات الهاتف أو ملف صوتي مخصص للتنبيه.

### القراءة الصوتية
- اختيار صوت من الأصوات المتاحة في الهاتف.
- دعم القراءة العربية للمراجع والأسئلة.
- إعدادات خاصة بتحسين النطق العربي.
- استمرار القراءة في الخلفية على Android.
- إشعار دائم أثناء القراءة مع زر لإيقاف الصوت.

### مركز الدراسة
- Flashcards.
- قاموس وملاحظات.
- Pomodoro.
- مراجعة ذكية.
- تحليل الأداء.
- سجل الجلسات.
- أدوات البحث وإدارة المحتوى.

### الإحصائيات
- نسبة النجاح وعدد الإجابات.
- الصحيح والخطأ.
- النشاط اليومي والأسبوعي والشهري.
- مقارنة الأداء الأسبوعي.
- أضعف وأقوى المحاور.
- أكثر الأسئلة خطأ.
- إحصائيات حسب بنك محدد أو جميع بنوك المجال.

### المظهر وتجربة الاستخدام
- العربية وRTL.
- وضع نهاري.
- وضع ليلي.
- وضع **حسب الهاتف** وهو الإعداد الافتراضي.
- Onboarding لأول تشغيل.
- جولات إرشادية داخل الشاشات الرئيسية.
- واجهة متجاوبة للهاتف والويب.

### التحكم عن بُعد
يستخدم Raje3 إعدادات خارجية من GitHub للتحكم في بعض الوظائف دون الحاجة إلى إصدار APK جديد، ومنها:
- معلومات آخر إصدار والحد الأدنى المدعوم.
- إشعارات وإعلانات داخل التطبيق.
- نافذة تقييم التطبيق.
- روابط التواصل الاجتماعي.

## التقنية

المشروع مبني باستخدام:
- React
- TypeScript
- Vite
- Tailwind CSS
- Capacitor
- SQLite محلي
- Android Native Java لبعض الوظائف مثل الإشعارات والتنبيهات والقراءة الصوتية

## تشغيل المشروع محليًا

```bash
npm install
npm run dev
```

## بناء نسخة الويب

```bash
npm run build
```

## بناء Android

يتم إنشاء مشروع Android وبناء APK من خلال GitHub Actions. ملف البناء الناتج يُرفع باسم:

`Raje3`

## ملاحظات البيانات

- قاعدة البيانات الحية للتطبيق داخلية ومحلية.
- ملفات Excel هي مصادر استيراد فقط وليست قاعدة البيانات نفسها.
- لا يتم تنفيذ SQL أو Macros أو صيغ Excel القادمة من الملفات المستوردة.
- بيانات المستخدم مثل الإحصائيات والأخطاء والمفضلة تبقى منفصلة عن ملفات البنوك.
