# منصة المراجعة - مفتشو الجمارك (Customs Study Web)

تطبيق ويب حديث ومتجاوب لمراجعة مباراة مفتشي الجمارك، مبني بواسطة React 18 وTypeScript وTailwind CSS وVite مع دعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (RTL).

## الميزات الرئيسية

- **الرئيسية (Home)**: إحصائيات عامة، نسبة النجاح، عدد الأسئلة والإجابات، والوصول السريع للمحاور والمراجعة.
- **بنك الأسئلة (Questions)**: تصفح الأسئلة مع البحث الفوري والمطابقة المتقدمة، وتصنيف المحاور، والإشارات المرجعية (المفضلة).
- **جلسات المراجعة التفاعلية (Quiz Sessions)**: مراجعة تفاعلية مع خيارات عشوائية وتصحيح فوري وشروحات تفصيلية وحساب نسب الإتقان واحتفالية النجاح.
- **مراجعة الأخطاء (Mistakes)**: تتبع ذكي للأسئلة غير الصحيحة مع إمكانية مراجعتها وإزالتها بعد التمكن منها.
- **المفضلة (Favorites)**: حفظ الأسئلة المهمة للرجوع إليها في أي وقت.
- **الإحصائيات والتقدم (Stats)**: رسوم دائرية ومؤشرات بيانية دقيقة للأداء ونسب النجاح والأسئلة المنجزة.
- **إدارة واستيراد بنوك الأسئلة (Question Banks)**: فحص واستيراد ملفات Excel (XLSX) مع التحقق الأمني الكامل والتنظيم حسب المحاور.
- **التذكيرات والإشعارات (Reminders)**: دعم إشعارات المتصفح وتخصيص الفترات الزمنية للمراجعة اليومية.
- **التكوين عن بُعد (Remote Config)**: مزامنة الإعلانات والتحديثات بشكل فوري ومستمر.

## تشغيل المشروع

```bash
# تثبيت الاعتماديات
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```
